## حریم خصوصی GitHub و توزیع

- مخزن اصلی GitHub را Private نگه دارید و به کسانی که نباید کد اصلی را ببینند دسترسی ندهید.
- مخزن Private برای افرادی که عضو یا دعوت‌شده نیستند قابل دانلود نیست؛ برای دوستان یک فایل ZIP جداگانه توزیع کنید یا پس از آماده‌سازی شرایط، افزونه را در Chrome Web Store نشر کنید.
- نکتهٔ مهم: در افزونهٔ Chrome که با Load unpacked نصب می‌شود، فایل‌های HTML، CSS، JavaScript، تصویرها و manifest روی کامپیوتر کاربر قرار دارند و قابل مشاهده یا تغییر محلی هستند. خصوصی بودن مخزن GitHub فقط از مخزن اصلی محافظت می‌کند و کد سمت کاربر را مخفی نمی‌سازد.
- بخش About از داخل رابط افزونه قابل ویرایش نیست. برای تغییر اطلاعات در نسخه‌های آینده، فایل `sidepanel.html` را ویرایش کرده، نسخهٔ تازه بسازید و دوباره توزیع کنید. نسخه‌های قبلی به‌طور خودکار تغییر نمی‌کنند.
- کلید API واقعی را در GitHub یا ZIP قرار ندهید. هر کاربر باید کلید خودش را وارد کند.

## تغییر معلومات تماس

در فایل `sidepanel.html` عبارت `CONTACT DETAILS` را جستجو کنید. کامنت HTML کنار آن محل معلومات تماس را مشخص می‌کند. مقدارهای `ADD_OFFICIAL_EMAIL_HERE`، `ADD_OFFICIAL_WEBSITE_HERE` و `ADD_OFFICIAL_PROFILE_HERE` را پیش از انتشار با معلومات رسمی خود جایگزین کنید.

در بخش About نوشته شده است که NR Company (نام کامل: Nooraqa Rasouli Company) در سال ۲۰۲۵ در کابل توسط Nooraqa Rasouli بنیان‌گذاری شده و روی ساخت وب‌سایت و سیستم‌های تحت وب، نرم‌افزارهای دسکتاپ، مدل‌های هوش مصنوعی محلی و آنلاین، افزونه‌های Online Voice Typing و Offline Voice Typing، Attendance Management System، Smart Learning Platform و Library Management System تمرکز دارد. این معرفی به‌عنوان پروفایل برنامه‌ریزی‌شدهٔ شرکت نمایش داده می‌شود و به‌معنای تأیید ثبت رسمی یا آماده بودن تمام محصولات نیست.
