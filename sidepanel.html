Recording behavior

Natural speech pauses create transcription segments. The Pause button stops microphone capture until you resume. Stop ends the session and releases microphone access.

Online Voice Typing is disabled on a fresh install. Microphone permission alone never permits audio uploads.

Quick start — how to use

  1. Open More Options → Transcription Settings and choose a supported provider.
  2. Paste your own API key into that provider's field and save it. Never use a key shared by someone else.
  3. Return to the home screen and select Enable microphone . Allow access in Chrome when prompted.
  4. Turn on Online Voice Typing . This is separate from microphone permission and means audio may be sent to the selected provider.
  5. Press Start recording , speak naturally, and pause briefly between phrases. Use Pause/Resume as needed and press Stop when finished.
  6. Use Copy or Export to save your transcript. Your transcript history stays in this browser profile unless you choose to share or export it.

Installation help: For a new installation, extract the downloaded ZIP, open chrome://extensions , enable Developer mode, click Load unpacked, and select the folder containing manifest.json .

Important: This extension requires an online transcription provider. Free quotas are not guaranteed, and a provider may be unavailable on some networks. If a provider is blocked, the extension cannot bypass that network restriction.

Audio and online processing

Audio is sent only when Online Voice Typing is enabled and an intended transcription action is running. Already submitted provider requests may finish after the toggle is turned off.

API key handling

API keys are stored in Chrome local storage on this browser profile. An extension that calls providers directly cannot guarantee key secrecy from someone who can inspect the profile or extension. Never share keys or the configured profile.

Local storage

Transcript history is stored locally and limited to the latest 20 records. Raw audio is not saved as history by default. You can delete individual records or clear the history.

Permissions

The sidePanel permission opens the side panel; storage keeps settings and transcript history; activeTab and scripting support user-requested text insertion; clipboardWrite supports copy actions. Provider host permissions allow only the listed transcription API domains.

About Online Voice Typing

Online Voice Typing is a Chrome extension for turning speech into text through a user-selected online transcription provider. It does not include an offline AI model. Provider availability, data handling, quotas, and pricing may change.
