VoiceFlow Online v2.0.0 — گزارش آزمون و بررسی
=============================================
تاریخ: ۲۰۲۶-۱۰-۱۵

محدودیت مهم
-----------
آزمون‌ها روی فایل‌های منبع انجام شده‌اند: بررسی نحو JavaScript و فایل manifest، آزمون رابط با API شبیه‌سازی‌شدهٔ Chrome، و آزمون‌های Node با MediaRecorder و پاسخ‌های API ساختگی. در این محیط افزونه در Chrome نصب‌شده با میکروفون واقعی، کلیدهای واقعی یا درخواست زندهٔ سرویس‌دهنده‌ها آزمایش نشده است. بنابراین این گزارش ادعا نمی‌کند که چنین آزمون‌هایی موفق بوده‌اند.

آزمون‌های موفق
--------------
۱. نحو JavaScript: تمام فایل‌های JavaScript توزیع‌شده از بررسی `node --check` گذشتند.
۲. Manifest: فایل manifest.json به‌درستی JSON است، از Manifest V3 استفاده می‌کند و مسیرهای service worker، پنل جانبی و آیکن‌ها موجود اند.
۳. HTML: شناسه‌های تکراری و ارجاع‌های محلی ناموجود بررسی شدند؛ پنل کناری هشت نمای جداگانه دارد.
۴. CSS: فایل‌های CSS با ابزار تجزیهٔ موجود بررسی شدند و خطای نحوی گزارش نشد.
۵. آزمون رابط با API شبیه‌سازی‌شدهٔ Chrome:
   - برنامه ابتدا صفحهٔ اصلی را نشان می‌دهد.
   - Online Voice Typing در نصب تازه خاموش است.
   - تغییر تم کار می‌کند.
   - شش کارت More Options به صفحهٔ جداگانه می‌روند و دکمهٔ برگشت دارند.
   - هشدار عدم تطابق پیشوند کلید نمایش داده می‌شود، ولی کلید خودکار به سرویس دیگری منتقل نمی‌شود.
   - روند ساختگی ذخیرهٔ کلید کار می‌کند.
   - تغییر زبان گفتار، زبان و جهت کل رابط را به‌طور ناخواسته تغییر نمی‌دهد.
   - جهت متن راست‌به‌چپ و شمارندهٔ نویسه بررسی شدند.
   - در جریان اقدامات آزموده‌شده خطای Console ثبت نشد.
۶. چرخهٔ ضبط با MediaRecorder/stream ساختگی: Start، Pause، Resume، Stop، توقف هنگام Pause، آزادسازی منابع و پایان جلسه موفق بود.
۷. آزمون درخواست‌های سرویس با fetch ساختگی:
   - درخواست multipart و خواندن پاسخ Groq.
   - بدنهٔ درخواست و خواندن پاسخ OpenRouter.
   - بارگذاری فایل Gemini، درخواست رونویسی Interactions و تلاش برای DELETE فایل موقت.
   - نشانی‌ها و جریان آزمون اتصال هر سه سرویس.
۸. بررسی‌های امنیتی/منبع: کلید API واقعی یا شبیه واقعی، کد پویای ناامن (`eval` و `new Function`)، بارگذاری JavaScript از راه دور و وابستگی زمان اجرا به Python بررسی شدند.
۹. اعتبارسنجی تاریخچه: زمان‌های بیرون از محدودهٔ قابل قبول رد می‌شوند تا نمایش تاریخ خراب نشود.
۱۰. بسته‌بندی ZIP: سلامت آرشیو، قرارگرفتن manifest.json در ریشه و هماهنگی محتویات آرشیو با پوشهٔ منبع بررسی شدند.

مهم‌ترین تغییرات
----------------
- تقسیم More Options به شش صفحهٔ جداگانه با سبک نزدیک به تصویر مرجع.
- افزودن سه بخش مستقل برای کلیدهای Groq، Gemini و OpenRouter.
- افزودن Pause/Resume واقعی و چرخهٔ حالت ضبط، شامل Stop هنگام Pause و آزادسازی میکروفون.
- خاموش بودن پیش‌فرض Online Voice Typing و جداسازی رضایت ارسال صدا از اجازهٔ میکروفون.
- جداسازی جهت زبان رابط از جهت متن گفتار.
- بهبود پیام‌های اجازهٔ میکروفون و درخواست‌های صوتی/API.
- محدودکردن تاریخچه و اعتبارسنجی زمان‌ها.
- به‌روزرسانی مستندات انگلیسی/دری و یادداشت‌های امنیتی.
- حذف پیکربندی کلید شخصی از بستهٔ توزیعی.

مواردی که در این محیط تأیید نشده‌اند
-----------------------------------
- نصب و اجرای ZIP از مسیر chrome://extensions در Chrome واقعی.
- رفتار واقعی اجازهٔ میکروفون Chrome و تنظیمات میکروفون سیستم‌عامل.
- ضبط با میکروفون فیزیکی، مرزبندی سکوت و زمان‌بندی در مرورگر واقعی.
- رونویسی زنده با کلید و حساب واقعی Groq، Gemini یا OpenRouter.
- سهمیهٔ رایگان مربوط به حساب شما، صورتحساب، فعال‌بودن مدل، سقف فایل یا دقت زبانی فعلی.
- درج متن در وب‌سایت‌های واقعی مختلف و صفحات محافظت‌شدهٔ Chrome.
- کیفیت واقعی تشخیص دری، فارسی، پشتو، عربی، اردو و گفتار چندزبانه.
- آزمون نفوذ مستقل یا ارزیابی رسمی امنیت و حریم خصوصی.

آزمون دستی پیشنهادی
-------------------
۱. پوشهٔ استخراج‌شده را از طریق chrome://extensions، گزینهٔ Developer mode و Load unpacked نصب کنید.
۲. بررسی کنید صفحهٔ اصلی باز شود و Online Voice Typing تا زمان فعال‌سازی خاموش بماند.
۳. گزینهٔ آنلاین را فعال کنید، اجازهٔ میکروفون بدهید و Start/Pause/Resume/Stop را آزمایش کنید. پس از Stop تأیید کنید که میکروفون دیگر فعال نیست.
۴. با یک حساب آزمایشی و فایل صوتی کوتاه و غیرحساس، هر سرویس را جداگانه امتحان کنید. پیش از آن وضعیت هزینه و سهمیه را بررسی کنید؛ رایگان بودن تضمین نشده است.
۵. فایل صوتی کوچک، ذخیره/بازگردانی/حذف تاریخچه، خروجی TXT، درج متن در کادر عادی وب و جهت رابط/متن دری را امتحان کنید.
۶. خطاهای افزونه در Chrome، داشبورد حساب سرویس‌دهنده و دقت متن نهایی را بررسی کنید.


## بررسی تکمیلی (2026-10-18)
- بررسی نحوی JavaScript برای فایل‌های recorder.js، sidepanel.js و i18n.js موفق بود.
- دکمهٔ قطع/فعال‌سازی میکروفون به ترک‌های صوتی MediaStream وصل شده و حالت آن هنگام مکث و ادامه حفظ می‌شود؛ در شروع ضبط تازه دوباره فعال می‌شود. رفتار با میکروفون واقعی در این محیط آزمایش نشده است.
- هنگام شروع ضبط تازه، فقط متن ویرایشگر اصلی پس از موفقیت بررسی‌های لازم پاک می‌شود؛ تاریخچهٔ ذخیره‌شده حذف نمی‌شود.
- آزمایش در Chrome نصب‌شده و درخواست‌های زندهٔ سرویس‌ها هنوز تأیید نشده است.
